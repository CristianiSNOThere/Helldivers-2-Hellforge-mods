# Super Earth Arsenal Modpack for HellForge

[Download v2.4.2](https://github.com/CristianiSNOThere/Helldivers-2-Hellforge-mods/releases/tag/hellforge-modpack-v2.4.2) | [Installation](INSTALL.md) | [All weapon and equipment changes](PLAYER-GUIDE.md)

25 independently selectable weapon and equipment mods, plus 29 One True Flag damage presets. Includes the backpackless AC-8, Rapid/Supercharge ARC-3, 150-round VG-70, dual-mode Punisher Plasma, Gas Overhaul and the Sickle/Double-Edge rework.

Requires HellForge SDK 11 and game build 25480438. The download contains C sources and tools to prepare the selected assets from your own supported HellForge installation. Follow [INSTALL.md](INSTALL.md) before enabling it. Python 3.10 or later and PowerShell 7 are required for preparation.

Edit `pack-config.json` to choose the options. Read [PLAYER-GUIDE.md](PLAYER-GUIDE.md) for every changed behavior and stat. Use this HellForge pack in place of the Arsenal Lua pack for the same session.
