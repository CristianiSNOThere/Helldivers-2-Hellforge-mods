# Tenderizer Armor Softener v0.1.2

AR-61 Tenderizer bullets apply Acid Storm, temporarily reducing enemy armor effectiveness for 15 seconds.

| Setting | Stock | Modded |
| --- | --- | --- |
| Magazine capacity | 35 rounds | 70 rounds |
| Normal / durable damage | 105 / 30 | 90 / 30 |
| Bullet launch speed | 820 m/s | 1,000 m/s |
| Direct-angle penetration | AP2 | AP3 |
| Slight-angle penetration | AP2 | AP3 |
| Large / extreme-angle penetration | AP2 / AP0 | AP2 / AP0 |
| Base sway | 1.0 | 0.9 |
| Acid Storm on bullet hits | None | 15-second armor reduction |

The existing 600/850 RPM settings, recoil, spread, spare-magazine counts and projectile drag remain unchanged. Armor reduction is temporary; it does not permanently destroy armor plates. The shared 15-second Acid Storm duration also affects the weather status after exposure ends.

## Install

Import the ZIP into Arsenal, enable its option, keep Bingus Shared Loader at its documented priority, Purge and Deploy, then restart Helldivers 2. Allow up to two minutes after reaching the ship for initialization. Requires Helldivers 2 Steam build 25480438 and Bingus Shared Loader v19.

Use the individual packages or the complete modpack. Enabling both duplicates the same add-on resources.
