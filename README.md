# Helldivers 2 Hellforge mods

HellForge mods for Helldivers 2. Each project has its own download and release; only the latest release of each HellForge project is kept.

## Super Earth Arsenal Modpack

[Download v2.4.4](https://github.com/CristianiSNOThere/Helldivers-2-Hellforge-mods/releases/tag/hellforge-modpack-v2.4.4) | [Installation](hellforge/modpack/INSTALL.md) | [Complete changes](hellforge/modpack/PLAYER-GUIDE.md)

25 independent weapon and equipment options and 29 One True Flag damage presets. Includes a backpackless AC-8, Rapid/Supercharge ARC-3, 150-round VG-70, dual-mode Punisher Plasma, Gas Overhaul, and Sickle/Double-Edge changes.

The source download prepares its selected assets from your own supported HellForge installation. Requires HellForge SDK 11 or newer, game build 25480438, Python 3.10 or later and PowerShell 7. Follow the installation instructions before enabling it.

Compatible with Scope of Authority Backport 2.14.15 on HellForge 0.1.28. Gas Overhaul also supports the 150-health Health Rework with either 2 or 2.8 health per second regeneration.
